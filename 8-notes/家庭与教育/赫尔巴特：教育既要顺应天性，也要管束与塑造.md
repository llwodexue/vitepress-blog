# 赫尔巴特：教育既要顺应天性，也要管束与塑造

> **教育面对的根本矛盾，是既要顺着孩子的天性，又要管束他、塑造他。** 如果只强调"把孩子当孩子"、顺应自然，那么一味顺着孩子来，他就一定能长成好人吗？赫尔巴特的回答是：不能——教育还有规范行为、塑造品格的功能。

前面谈卢梭和皮亚杰时，核心是顺应孩子的发展阶段、不揠苗助长。但顺应天性不等于放弃约束。德国教育学家赫尔巴特（科学教育学的奠基人，其《普通教育学》被视为西方教育科学的开山之作）补上了这条线索的另一半：孩子需要被看见，也需要被管理。

下面从他的思想中提炼四个要点，分别回答：教育者该懂什么、孩子该怎么管、该教什么知识、性格能不能被塑造。

## 先回答四个问题

| 问题 | 赫尔巴特的回答 | 指向的重点 |
| --- | --- | --- |
| 发现孩子的特长靠什么？ | 先懂心理学，再靠持续观察 | 教育者的素养 |
| 孩子需要被管束吗？ | 需要；处罚既是纠错，也是对他人公平 | 管理与边界 |
| 该让孩子学什么？ | 德育优先，再区分"必要性"与"可能性"知识 | 教育的目的 |
| 性格是天生的吗？ | 不完全是；教育能通过"训育"塑造性格 | 品格的形成 |

## 发现特长，靠懂心理学与持续观察

很多家长以为，要辅导孩子数学，自己得先搞懂数学；送孩子去辅导班，也是冲着具体课程去的。赫尔巴特却把顺序反了过来：**教育者要了解的第一门科学，不是任何具体学科，而是心理学。**

这不是让每个家长都去系统学心理学，而是说：教育的起点不是"教什么"，而是"了解被教育的人"。懂一点心理，才知道孩子的能力发展到了哪一步，自己的要求是否超出了他的认知水平。

> 换句话说，先懂孩子，再谈怎么教。

只懂心理学还不够，还要持续观察。赫尔巴特认为，孩子的个性和特长是被"发现"出来的，而不是被"设计"出来的。教育者不能只按自己的构想去培养孩子——这样既可能搞错方向，阻力也会很大。偷懒的做法是看别人家孩子学什么，自己家就跟着学，结果往往既埋没了孩子的天赋，又浪费了大量精力。

## 孩子需要被管束，处罚有时是必要的

::: tip 核心提醒
顺应天性，不等于放弃管束。孩子不会天生带着意志来到世上，恰恰是在被管束的过程中，才慢慢学会意志与规则。
:::

赫尔巴特生活在普鲁士时期，今天看确实过分强调管束，这一点要放回时代去看。但他有两个提醒，放到今天仍然成立。

**第一个提醒：管束要有方法，否则孩子学会的是你的坏毛病。** 父母管束孩子时，是带着自己的意志去的；孩子能感受到这种意志，并慢慢学会它。如果父母脾气暴躁、用羞辱施压，孩子学会的可能不是规则，而是同样的暴躁与羞辱。所以管束的重点不在"压住"，而在用对方式——管不好，反而让孩子学会了家长的坏毛病。

**第二个提醒：犯错后需要接受处罚，这与"爱孩子"并不矛盾。** 处罚有两个目的：一是让孩子知道什么不能做，防止小错拖成大错，成年后危害他人；二是对被伤害的人公平——有人作弊却不处理，对其他守规则的学生就不公平；打人了没有后果，对被欺负的同学也不公平。

一个现代的例子能说明这种"对他人公平"有多严肃：在美国库帕蒂诺（苹果公司所在地）的学区，一名男生反复纠缠同班女生，被拒绝后递上写有威胁内容的纸条。女生家长本想请老师劝导，老师却直接报警。第二天警察搜查了学校和男生家里，男生被限制活动范围，最终因不当行为被要求转学，全家不得不搬家。按这里的逻辑，处罚不是私人恩怨，而是让规则与公平重新生效。

> 处罚的价值，不在于让孩子害怕，而在于让他明白"什么不能做"，以及"伤害他人是有后果的"。

中国教育部制定的《中小学教师实施教育惩戒规则》，本意也在于此：既避免老师随意处罚，也保证学校能依法对违纪学生进行正常约束。这正是"孩子需要管理"在今天的一种制度化表达。

## 德育优先，再区分"必要性"与"可能性"的知识

赫尔巴特强调，教育的目的是让孩子有更好的未来，而不是为了国家这类看不见具体人的宏大目标。人的追求是多方面的，教育的目的也应该是多方面的；而在这一切之中，**排在第一位的应该是德育，其次才是知识传授。**

在知识传授上，他做了一个很实用的区分：

| 知识类型 | 目的 | 例子 |
| --- | --- | --- |
| 必要性知识 | 不学就难以在社会立足，保证谋生能力 | 编程、读写、通识教育 |
| 可能性知识 | 为实现人生梦想而学，能否兑现不确定 | 艺术、理想主义的追求 |

这个区分的用处，是让人别把两件事混为一谈。假如孩子想当艺术家，但现实是只有极少数人能纯靠艺术养活自己，这时他需要先确保谋生的能力——比如学一门能安身立命的专业；艺术则作为"可能性"去追求。很多人在选目标时陷入单一思维，非要把必要性和可能性搅在一起，结果人生道路越走越窄。

对未成年人，赫尔巴特主张教育者要帮他确定"必要性的目标"。孩子缺乏社会经验，选择难免出错，教育者的责任是帮他认清什么才是真正好的选择，引导他学有益、有用的知识。否则，一个大学毕业、学了十几年的人，若所学对他立业成人毫无用处，那份高学历除了带来自负，给不了他任何真实的好处。

## 性格不是天生的，教育能塑造它

人们常说"性格决定命运"，那么性格是天生的吗？赫尔巴特的答案是否定的——**教育对性格的形成能起决定性的作用。**

他把教育对性格的塑造称为"训育"（德语 Zucht），指那些直接作用于青年心灵、塑造心灵的教育。具体来说，教育可以从六个维度影响孩子的性格：

| 维度 | 培养什么 |
| --- | --- |
| 规则 | 遵守规则的习惯 |
| 判断 | 判断力 |
| 适应 | 适应环境的能力 |
| 涵养 | 克制冲动的涵养 |
| 道德 | 道德水准 |
| 反思 | 反思能力 |

这六个方面做得好，孩子的性格就更成熟、更完善，性格培养才算成功。

::: info 适用边界
"教育塑造性格"不等于"性格可以任意改造"。它说的是：性格并非纯然天成，后天教育有真实的作用空间。这与前面讲"顺应天性"并不冲突——顺应的是发展阶段，塑造的是品格与习惯，二者面向的是不同层面。
:::

## 行动建议

::: tip 本周行动
在本周选一个你想"顺着孩子"或"直接管束"的时刻，先停下来分辨：此刻的问题是**发展阶段的限制**（孩子还做不到），还是**行为与品格的边界**（孩子做了不该做的事）？

前者用顺应和等待，后者才用约束和后果。别把方法用错地方。
:::

把顺应天性和管束塑造放进同一套思路里，教育才不是走钢丝，而是两条腿走路。
