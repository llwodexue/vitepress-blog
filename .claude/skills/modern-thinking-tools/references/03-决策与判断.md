# 模块三：决策与判断（16个工具）

这是整套课程的技术核心。一句话概括这一层的世界观：**决策决的不是单次结果，而是一个概率分布；你能决定的是过程，更严格地说，是你放弃哪些东西。**

处理任何真实决策，建议按这个顺序过一遍：
偏置（我想要什么）→ 分布（这是个什么形状的赌局）→ 证据（我该收集什么信息）→ 下注（多大规模、能不能承受最坏情况）→ 纠偏（我的观测本身可靠吗）→ 迭代（怎么边做边改）。

---

## 无免费午餐定理（No Free Lunch）
- **内核**：想在一个领域比别的算法好，就必然在另一个领域比别的算法差。你必须先*主观*选一个领域、设定归纳偏置，才谈得上理性推算。不管过程多理性，决策的初心一定是一个任性。
- **何时用**：当事人要求"客观最优解"；在多个不可通约的选项之间瘫痪。
- **怎么用**：三步心法——强先验设定偏置 → 算法搜索 → 系统化冒险。先逼出"你到底要什么"，再谈优化。
- **误用**：用它为拍脑袋辩护。偏置是搜索的起点，不是结论。

## 概率分布（What a Decision Really Is）
- **内核**：决策至少要看六个参数：均值（期望）、方差、上限、下限、偏度、峰度、稳健性。高水平决策者像斯多葛的射箭手——尽全力拉弓瞄准（可控的过程），对箭离弦之后保持冷静的漠然。
- **何时用**：任何"这个选择好不好"的问题。
- **怎么用**：把选项翻译成分布，尤其问：最坏情况是什么？会不会清零？上行空间被截断了吗？
- **误用**：只比较期望值。对个体而言下限比均值更要命（见非遍历性）。

## 颗粒度与因果中介（Granularity & Causal Mediation）
- **内核**：要操控一个事物，必须在头脑中建立它的模型（好调节器定理）。好模型两个要求：颗粒度恰到好处（达到最小描述长度），且包含因果关系而非相关关系。
- **何时用**：问题复杂、说不清机制、各方在争论"到底是什么导致了什么"。
- **怎么用**：画出 A→B→C 的机制链，标出中介变量；问"如果我干预 X 而其他不变，会怎样"。
- **误用**：模型越细越好。多了也不好少了也不好。

## 贝叶斯先验（Bayesian Prior）
- **内核**：后验 = 先验 + 证据更新。概率是信念的度量，是对你无知程度的量化。两种典型错误：完全没有先验；先验不可动摇。
- **何时用**：几乎所有判断题；尤其是新信息刚到、想立刻改主意或坚决不改主意时。
- **怎么用**：先根据环境参数设一个数字化的先验，再把具体事件当证据，小步更新。
- **误用**：假装算了贝叶斯，其实数字是硬凑的。写出来的先验哪怕粗糙也比不写好。

## 信息价值（Value of Information, VOI）
- **内核**：只有当一条信息能够改变你的实际行动时，它才有价值。VOI = 有这条信息时的最佳选择比没有时的最佳选择平均能多赚多少。高价值信息三个特征：目标导向、带有痛感、出现在决策边界上。
- **何时用**：要不要继续调研、要不要做用户访谈、信息过载、"我还需要知道什么"。
- **怎么用**：对每条待收集的信息问："知道之后我会改变哪个动作？"答不上来就别花时间。
- **误用**：把"有意思"当成"有价值"。

## 凯利公式（Kelly Criterion）
- **内核**：在不确定的、乘法式结算的、可重复的世界里该下多大注，才能让长期增长率最大。凯利让你赚的是你超出大众认知的那部分——你比大众高明多少，它就帮你赚多少，不能更多。你的增长上限受限于你的认知带宽。
- **何时用**：投资、创业投入、时间分配、要不要 all in。
- **怎么用**：三个底层指引——别把自己清零；认知先行（先问 edge 有多大，再想注下多大）；追求复利而不是赢一把。
- **误用**：满仓即最优。实际中通常用半凯利或更保守，因为你对 edge 的估计本身有误差。

## 非遍历性（Non-ergodicity）
- **内核**：集合平均 ≠ 个体的时间平均。数学期望是上帝视角的平均，时间平均才是凡人视角的命运。玩家怕方差，庄家爱方差。
- **何时用**：任何有"归零风险"的决策；杠杆、赌博式创业、健康、法律风险。
- **怎么用**：四个策略——减少交易次数；杠铃策略（大部分极安全 + 小部分极激进，砍掉中间）；成为庄家；风险共担/分摊。
- **误用**：把它当成"别冒险"。它说的是别在会清零的地方重复冒险。

## 脆弱与反脆弱（Antifragility）
- **内核**：脆弱和反脆弱往往不是事物的绝对属性，而取决于你站在哪一边。稳定是一种幻觉——你要么脆弱，要么反脆弱。
- **何时用**：风险评估、组织韧性、个人职业结构。
- **怎么用**：应对脆弱：拆弹（否定法，做减法）+ 分拆压力（毁灭隔离、分块化）。践行反脆弱：见到非对称机会就下小注 + 主动注入不确定性（折腾）。
- **误用**：把"多元化"当反脆弱。关键是收益的凸性，不是数量。

## 期权（Optionality）
- **内核**：期权是权利不是义务。成立条件有二：未来存在多个可能路径；你对其中某个结果拥有专有进入权。BATNA 是一种看跌期权。有选项你就有杠杆。
- **何时用**：谈判、offer 选择、要不要提前锁定、"要不要留后路"。
- **怎么用**：波动性越大期权越值钱，到期时间越短越不值钱——所以要早买、别让它过期，并且记得算持有成本。
- **误用**：无限保留选项。期权有持有成本且会过期，不行权的期权价值为零。

## 状态杠杆（State Leverage）
- **内核**：这一步做完之后，世界会不会变得对下一步更友好。总收益 = 即时回报 + 下一个状态的潜在价值。三种：前置杠杆（上游设计阶段，越早的决定锁定效应越强）、顺序杠杆（信息依赖决定的严格次序）、约束杠杆（先解决瓶颈，别急着优化全流程）。
- **何时用**："我很努力但没进展"、项目排期、精力分配。
- **怎么用**：找出瓶颈；把高锁定效应的决定提前；按信息依赖排序而不是按容易程度排序。
- **误用**：无止境地"做准备"。前置杠杆也要受可承受损失约束。

## 选择偏差（Selection Bias）
- **内核**：进入你视野的样本并不等概率代表真实世界。四类：自我选择偏差（来的人都是想来的）、幸存者偏差（没来的是来不了）、分组选拔偏差（一开始就不是随机分组）、门槛偏差/伯克森悖论。
- **何时用**：听到任何案例、榜样、成功学、用户反馈、行业"共识"时。
- **怎么用**：听到故事先问四句——谁没来？谁来不了？分组是随机的吗？这里有没有门槛？
- **误用**：用它否定一切经验。目的是校正权重，不是拒绝信息。

## 回归均值（Regression to the Mean）
- **内核**：观测结果 = 真实水平 + 随机运气。极端值罕见，所以下一次自然没那么极端。两类回归谬误：错把波动当因果，错把运气当实力。
- **何时用**：业绩暴涨/暴跌后要不要大动作；孩子考砸了；批评与表扬的效果评估。
- **怎么用**：问四句——我是不是因为一个极端值才开始注意它？我看的是一个点还是多期数据？如果什么都不做它会不会自己缓回来？系统的生成机制真的变了吗？
- **误用**：用它解释掉一切变化，从而对真实的机制变化视而不见。

## 前景理论（Prospect Theory）
- **内核**：人看的不是预期效用，而是相对于心里那个「参照点」是赚还是亏。在参照点右侧就守成，左侧就押注。让人铤而走险的不是贪婪，而是不甘。四个衍生偏误：损失厌恶、现状偏见、禀赋效应、框架效应。
- **何时用**：对方在做高风险动作、死扛沉没成本、谈判僵持、销售与说服。
- **怎么用**：先找出对方的参照点在哪，很多"不理性"立刻就解释得通了。高手应该自由设置自己的参照点——它应该是激励而不是枷锁。
- **误用**：只当它是"人有偏见"的清单。它的操作价值在于挪动参照点。

## 参考类预测（Reference Class Forecasting）
- **内核**：内部视角看个案信息，外部视角看分布信息。规划谬误让人系统性低估时间、成本和风险，同时高估收益。
- **何时用**：任何"这个项目要多久/多少钱/成功率多高"的估计。
- **怎么用**：三步——① 找一组和你足够相似且已经结束的案例（不是你喜欢的榜样）；② 找出这个参考类的基准线（平均成本、时间、失败率）；③ 把自己放进去微调：我更像中位数还是该更保守？
- **误用**：内外视角混用。做事时用内部叙事打气，决策时必须用外部参考类泼冷水。

## 超级预测（Superforecasting）
- **内核**：两件事——概率化 + 可检验。概率化三步：把"云状问题"拆成可判定的小问题；用外部视角打底、内部视角微调；贝叶斯更新。检验看校准度（概率准不准）和区分度（敢不敢给极端概率，别和稀泥都说50%），指标是布里尔分数。
- **何时用**：重大不确定判断；团队争论谁对谁错；想提升判断力本身。
- **怎么用**：把结论写成"X 事件在 Y 时间前发生的概率是 Z%"，记录下来，事后打分。
- **误用**：只预测不记分。不记分就没有校准，工具就退化成表演。

## OODA 环
- **内核**：观察 → 定向 → 决策 → 行动的循环。深意不是做一次正确决策，而是边行动边学习边修正。四个字母里最关键的是第二个 O，定向——不是反应快，而是换脑快。
- **何时用**：竞争对抗、局势快速变化、信息不足却必须行动。
- **怎么用**：不是求定论，而是先下小注；不是做完一步，而是让每一步都带回下一步的情报。
- **误用**：把 OODA 当作"快速执行"。定向环节被跳过时，速度只会让你更快地错下去。
