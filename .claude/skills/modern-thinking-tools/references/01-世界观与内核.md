# 模块一：世界观与内核（10个工具）

这一层不解决具体问题，它决定你看问题的默认镜头。当一个人的困境反复出现、换了环境也一样，多半是这一层出了问题——他还在用「稳态生存逻辑」（资源匮乏 + 强从众 + 简单线性模型）应对一个高波动世界。

---

## 叙事（Narrative）
- **内核**：世界不是事实堆，是叙事场。叙事是把一系列事实串起来的线索结构（时间顺序、目标取向、命名定性、身份宣告或立场承诺），其中潜伏着可验证的因果关系，能引导行动、校准情绪。
- **何时用**：当事人被"事情就是这样"困住；团队士气问题；情绪与事实明显不匹配；需要说服他人。
- **怎么用**：① 把对方正在运行的那个故事说出来（谁是主角、什么因果、结局指向哪）；② 检查其中的因果是否可验证；③ 换一根线索重讲一遍，看行动选项是否变了。
- **误用**：叙事不等于自欺或编故事。好叙事必须能被现实检验，且能真的引导出下一步动作。

## 重尾（Heavy Tail）
- **内核**：回报不是平均分配，是极端涌现。加法世界里"你的增量 = 固定工资"；乘法世界里"你的增量 = 当前动作 × 你的存量"。
- **何时用**：抱怨"我很努力但没回报"；在评估一份工作/一门生意值不值得；纠结要不要"面面俱到"。
- **怎么用**：① 问这件事的回报分布是加法还是乘法；② 找出能让存量参与放大的那个杠杆（资本、网络效应、声望、可复用资产）；③ 停止在无杠杆处求平均用力。
- **误用**：重尾不是"赌一把"。它要求的是正反馈结构，不是高方差豪赌（配合凯利公式与非遍历性一起用）。

## 能动（Agency）
- **内核**：平庸观念的共同特征是追求稳定，其三大基因是资源匮乏、强从众、用简单模型看世界。世界已经高波动，观念却滞后。关键区别是：你是调用工具的人，还是别人的工具。
- **何时用**：当事人反复说"没办法""大家都这样""等等看"；决策被他人期待绑架。
- **怎么用**：① 指出他正在执行的是谁的默认设置；② 区分"真约束"和"想象出来的从众压力"；③ 至少设计一个由他自己发起的动作。
- **误用**：不是鼓吹莽撞。能动必须和「约束」配套，否则是幻想。

## 约束（Hard Constraints）
- **内核**：现实是硬约束之网——资源、时间窗口、物理与规律、以及他人的能动性。最简单的约束检验就是算账。
- **何时用**：任何计划落地之前；对方描述的方案听起来很美。
- **怎么用**：① 盘资源（钱、时间、注意力、关系）；② 看窗口（现在还来不来得及）；③ 尊重规律（有没有违反已知机制）；④ 承认他人也有自己的目标，不会配合你的剧本。
- **误用**：用约束当放弃的借口。约束是用来重新设计路径的，不是用来证明不可能的。

## 可能（Uncertainty）
- **内核**：世界天生有计算不可约性和奈特不确定性，给不了你绝对确定。层级是：抗拒不确定性 < 接受 < 拥抱 < 制造。不确定性是加工"意义"的燃料。
- **何时用**：当事人的核心诉求是"我想要确定""我怕万一"。
- **怎么用**：① 区分可算概率的风险和根本算不出的奈特不确定性，两者对策不同；② 对后者别求预测，求结构（可选项、反脆弱、小注试错）。
- **误用**：把"拥抱不确定性"讲成鸡汤。它必须落到具体的下注规模和退出条件上。

## 内核（Three Selves）
- **内核**：人有三个自我——进程自我（当下的念头情绪）、界面自我（对外的人设）、内核自我（价值观与模型参数）。真正的成长是改写内核，不是修饰界面或压制进程。
- **何时用**：反复的自我否定、人设疲惫、"我到底想成为什么人"。
- **怎么用**：判断问题出在哪一层，再对症：进程层用认知解耦；界面层用身份认同；内核层要改的是"你想成为什么人"这个选择。
- **误用**：把情绪问题当内核问题处理，会导致过度自我批判。

## 能耐寻求定理 / 赋能（Empowerment）
- **内核**：智能体尽量争取自己未来拥有更多可能性，就能在绝大多数情况下最大化奖励。赋能 = 增加未来状态的信道容量：如果这个动作能带你到一个通向更多不同未来的位置，它就是赋能。君子不器。
- **何时用**：两个选项收益相近；不知道该学什么、去哪个城市、接哪个项目。
- **怎么用**：不比较即时收益，比较"做完之后你的选项集变大还是变小"。
- **误用**：无限囤积选项而永不兑现（见探索与利用、期权的持有成本）。

## 供给侧心态（Supply-Side Mindset）
- **内核**：不问"我能得到什么"，问"我能提供什么"。三件事：价值生产（真能解决问题）、摩擦消除（让别人跟你合作更省事）、网络触达（你能进入什么级别的合作圈层）。
- **何时用**：谈判、求职、分配、竞争、冲突、亲密关系里出现"我是不是吃亏了"的算计。
- **怎么用**：把"名额之争"改写成"这件事真正缺的供给是什么，我能不能补上"。哪怕这次没赢，也表现得像个体面的专业人士——这场比赛的观众是下一场的队友。
- **误用**：变成无底线付出。供给侧不是奉献，它要求你嵌入长期重复博弈且有网络效应的结构里。

## 复利（Compounding）
- **内核**：成功最重要的不是利率多高，而是持续时间多长。七种可积累的资本：金钱、人力、健康、社会、声望、心理、体验。年轻的强是增长，中年的强是杠杆，老年的强是取舍。
- **何时用**：职业规划、要不要跳槽/换城市、评价一件事"值不值得做"。
- **怎么用**：问三句——这件事会不会留下存量？这个存量会不会影响我以后的机会？中断它的成本有多大？
- **误用**：把复利当作"熬资历"。熬时间是加法，复利要求本次成果能进入下次的本金。

## 自我决定理论（Self-Determination Theory）
- **内核**：动机质量比强度更重要。三种基本心理需求：自主感、胜任感、关系感。三者被满足则能动性自动发芽，被压制则动机枯萎。「过度理由效应」：外部控制（钱、考核）会挤掉内在动机。
- **何时用**：拖延、倦怠、"喜欢的事却启动不了"、带团队、教育孩子。
- **怎么用**：逐项诊断三种需求哪一项缺失，针对性补——自主感给选择权和理由，胜任感给可达成的下一步，关系感给真实的连接。
- **误用**：用它否定一切外部激励。钱不是敌人，"控制感"才是。
