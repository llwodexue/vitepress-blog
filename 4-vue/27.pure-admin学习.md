# pure-admin学习

## 项目概述

[vue-pure-admin](https://github.com/pure-admin/vue-pure-admin) 是一款基于 Vue3 + Vite + TypeScript + Element Plus 的开源中后台管理模板，特点如下：

- 使用 Composition API 编写组件，代码扁平化
- 基于 `unplugin` 系列插件实现组件、API 的自动导入
- 使用 Pinia 做状态管理，支持持久化
- 完善的权限路由系统（前端静态路由 + 后端动态路由两种模式）
- 支持暗黑模式、多主题色切换
- 封装了常用 Hooks 和工具函数

## 环境配置

> 为了防止意外地将一些环境变量泄漏到客户端，只有以 `VITE_` 为前缀的变量才会暴露给经过 vite 处理的代码

在 `.env` 文件中添加自定义配置 `VITE_HANDSOME = true`

1. 在 `.env` 中加入 `VITE_HANDSOME = true`

   ```shell
   # 自定义配置
   VITE_HANDSOME = true
   ```

2. 在 `global.d.ts` 加入类型支持，在 interface ViteEnv 里加上 `VITE_HANDSOME: boolean`

   ```ts
   declare global {
     interface ViteEnv {
       VITE_HANDSOME: boolean;
     }
   }
   ```

3. 设置默认值，在 `build/utils.ts` 文件的 `ret` 变量上加上 `VITE_HANDSOME: true`

   ```ts
   const ret: ViteEnv = {
     VITE_HANDSOME: true
   }
   ```


## Vite插件

### vite-svg-loader

将 SVG 文件转换为可直接交互的 Vue/React 组件

```ts
import svgLoader from 'vite-svg-loader'

export default defineConfig({
  plugins: [
    vue(), 
    // svg组件化支持
    svgLoader()
  ]
})
```

使用方式

```ts
import iconUrl from './my-icon.svg?url'
// 'data:image/svg+xml...'

import iconRaw from './my-icon.svg?raw'
// '<?xml version="1.0"?>...'

import IconComponent from './my-icon.svg?component'
// <IconComponent />
```

### unplugin-auto-import

自动导入 Vue、Vue Router、Pinia 等 API，无需手动 import：

```bash
$ npm i unplugin-auto-import -D
```

```ts
// vite.config.ts
import AutoImport from 'unplugin-auto-import/vite'

export default defineConfig({
  plugins: [
    AutoImport({
      imports: [
        'vue',
        'vue-router',
        'pinia',
        {
          // 自定义导入映射
          'vue': ['defineProps', 'defineEmits', 'defineExpose']
        }
      ],
      dts: 'types/auto-imports.d.ts',
      dirs: ['src/hooks', 'src/store/modules']
    })
  ]
})
```

使用效果 — 直接调用无需 import：

```html
<script setup>
const route = useRoute()
const router = useRouter()
const count = ref(0)
const userStore = useUserStore()
</script>
```

### unplugin-vue-components

自动导入组件库中使用的组件：

```bash
$ npm i unplugin-vue-components -D
```

```ts
// vite.config.ts
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'

export default defineConfig({
  plugins: [
    Components({
      resolvers: [ElementPlusResolver()],
      dts: 'types/components.d.ts',

```

无需手动 import Element Plus 组件：

```html

```

## 路由与权限

### 路由配置

pure-admin 支持两种权限模式，通过配置项切换：

```ts
// store/modules/setting.ts
{
  routeMode: 'static' | 'dynamic'
}
```

**静态路由**：前端定义好完整路由表，通过 `meta.roles` 控制可见性：

```ts
{
  path: '/permission',
  meta: {
    title: '权限管理',
    roles: ['admin']           // 仅 admin 可见
  },
  children: [
    {
      path: 'page',
      component: () => import('@/views/permission/page.vue'),
      meta: { title: '页面权限' }
    }
  ]
}
```

**动态路由**：登录后接口返回路由表，前端动态添加：

```ts
// router/utils.ts
function initRouter() {
  const userStore = useUserStore()
  const asyncRoutes = userStore.getAsyncRoutes()
  asyncRoutes.forEach(route => router.addRoute(route))
}
```

### 权限指令

pure-admin 提供了 `v-auth` 指令控制元素级权限：

```html
<el-button v-auth="['admin']">管理员按钮</el-button>
<el-button v-auth="['editor', 'admin']">编辑按钮</el-button>
```

## 布局系统

pure-admin 内置多种布局模式：纵向、横向、经典、分栏等：

```ts
// 布局 store
const appStore = useAppStore()

// 切换布局
appStore.setLayout('vertical')   // 纵向布局
appStore.setLayout('horizontal') // 横向布局
appStore.setLayout('classic')    // 经典布局
```

菜单折叠、面包屑、标签页、全屏等功能均可通过 setting store 控制：

```ts
const settingStore = useSettingStore()
settingStore.toggleSidebarCollapse() // 折叠菜单
settingStore.toggleShowBreadcrumb()  // 显示/隐藏面包屑
settingStore.toggleShowTags()        // 显示/隐藏标签页
```

## 请求封装

基于 axios 封装，统一处理请求/响应拦截、token 注入、错误提示：

```ts
// utils/http.ts
import axios from 'axios'
import { getToken } from './auth'
import { message } from './message'

const http = axios.create({
  baseURL: import.meta.env.VITE_BASE_API,
  timeout: 30000
})

// 请求拦截 — 注入 token
http.interceptors.request.use(config => {
  const token = getToken()
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

// 响应拦截 — 统一错误处理
http.interceptors.response.use(
  response => {
    const { code, data, msg } = response.data
    if (code === 0) return data
    message.error(msg)
    return Promise.reject(new Error(msg))
  },
  error => {
    const { status } = error.response
    if (status === 401) {
      message.error('登录已过期，请重新登录')
      // 跳转登录页
    }
    return Promise.reject(error)
  }
)
```

页面中直接调用 API：

```ts
// api/user.ts
import http from '@/utils/http'

export const getUserInfo = () => http.get('/user/info')
export const login = (data: { username: string; password: string }) =>
  http.post('/user/login', data)
```

## 常用 Hooks

pure-admin 封装了一些实用的组合式函数：

```ts
// useBoolean — 布尔值切换
import { useBoolean } from '@/hooks/useBoolean'
const { bool, toggle, setTrue, setFalse } = useBoolean()

// useMessage — ElMessage 快捷调用
import { useMessage } from '@/hooks/useMessage'
const { success, error, warning, info } = useMessage()
success('操作成功')

// useFullscreen — 全屏切换
import { useFullscreen } from '@/hooks/useFullscreen'
const { isFullscreen, toggle } = useFullscreen()

// useCopy — 复制文本
import { useCopy } from '@/hooks/useCopy'
const { copyText } = useCopy()
await copyText('要复制的文本')

// usePagination — 分页逻辑封装
import { usePagination } from '@/hooks/usePagination'
const { page, size, total, handleSizeChange, handleCurrentChange } = usePagination()
```
